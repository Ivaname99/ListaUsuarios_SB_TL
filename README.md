#  Lista de Usuarios con Spring Boot y Thymeleaf

Este proyecto es una aplicación web desarrollada con **Spring Boot 3.4.5** y **Thymeleaf**, que muestra una lista simulada de usuarios con opción de filtrado en una interfaz moderna y responsiva.

------------

## Requisitos
Estos son los requisitos que debemos tener para ejecutar el programa correctamente. 

- Java JDK 21 instalado y configurado.
- IntelliJ IDEA.

------------

## Instrucciones para ejecutar el proyecto

#### 1. Clonar el repositorio

Ir al directorio en donde se colocará el proyecto, abrir git y clonar el repositorio con:

```bash
git clone https://github.com/Ivaname99/ListaUsuarios_SB_TL.git
```

------------

#### 2. Abrir el proyecto
- Abre IntelliJ IDEA
- Ve a File > Open.
- Navega hasta la carpeta del proyecto y haz clic en "Open".
> IntelliJ detectará automáticamente que es un proyecto Maven y descargará las dependencias.

------------

#### 3. Ejecutar el proyecto
En el panel izquierdo, en Proyect, ubica el archivo **UsuariosThymeleafApplicationTests.java**
